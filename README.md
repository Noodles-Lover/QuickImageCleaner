# QuickImageCleaner

把图片的纯色背景一键变透明，并裁掉四周多余的空白，导出为 PNG。

**在线使用（无需安装）：https://noodles-lover.github.io/QuickImageCleaner/**

---

## 适合什么图

**适合**：产品图、白底人像、扫描件、截图、图标素材 —— 背景是**纯色或接近纯色**的图片。

**不适合**：背景复杂、带渐变、毛发或半透明物体与背景交织的照片。这类图需要 AI 抠图工具。

---

## 特色

- **免费**：不用注册、不限张数、没有水印
- **开源**：代码公开，可自行查看与修改，也保证不会收集你的任何信息
- **快**：全程在你自己的浏览器里运算，没有上传等待。预览按降采样处理，拖滑块即时看到结果
- **离线**：所有处理都在本机完成，图片不会离开你的电脑，处理也不需要网络
- **方便**：支持批量处理，每张图能单独调参数，批量处理后图片按原名保存，不添加冗余的前后缀

## 三步上手

1. 打开网页，把图片**拖进**页面（也可以点击选择文件，或按 `Ctrl + V` 粘贴）
2. 确认背景色 —— 打开图片时会自动识别，不准就点「拾取」，再在图上背景处点一下
3. 点「导出 PNG（裁剪后）」或「导出 PNG（原尺寸）」

想先对比效果，勾选「显示原图」；想看边缘细节，可用滚轮放大。

---

## 批量处理

1. 点「选择文件夹」，选中存放图片的文件夹
2. 页面进入批量模式，用左右箭头或 `←` `→` 键逐张预览
3. 每张图都有**独立参数**（默认相同），背景色则是**每张单独自动检测**
4. 不逐张调整也可以 —— 直接点「开始处理」，全部按默认参数执行

保存方式有两种：

| 方式 | 原图 | 处理结果 |
| --- | --- | --- |
| **创建副本** | 另存为 `原名-original.jpg` | 使用原文件名 `原名.png` |
| **原地覆盖** | 不保留 | 使用原文件名 `原名.png` |

> **原地覆盖不可恢复**：原图会被直接改写（PNG）或删除（非 PNG），工具无法撤销。选择这项前会弹出确认，重要图片请先备份。

其他说明：

- 只处理文件夹**第一层**，不进入子文件夹，非图片文件自动跳过
- 导出始终按**原始分辨率**重新计算，与预览精度无关
- 写入文件夹依赖浏览器的 File System Access API，请使用 **Chrome 或 Edge**

---

## 支持的格式与限制

- **输入**：PNG / JPG / JPEG / JFIF / WebP / BMP / GIF / AVIF
- **输出**：PNG（带透明通道）
- 单张上限：4000 万像素、单边 16384 px
- GIF 只取第一帧，导出为 PNG 后不再有动画

## 隐私

图片处理全部在你的浏览器内完成，**不上传到任何服务器**，也不需要联网。页面加载了百度统计脚本用于了解访问情况，它不接触你的图片文件。

你也可以使用离线版本：把代码下载到本地，双击 `index.html` 就能运行（批量写入文件夹的功能需要 Chrome 或 Edge）。
